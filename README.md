# 다시봄 키오스크

중부대학교 졸업작품 「다시봄: AI 몽타주 기반 실종자 찾기 키오스크」(4인 팀, 2025.09 ~ 2026.09) 가운데 키오스크 화면과 하드웨어 연동 부분입니다.

## 이 저장소에 있는 것

- 키오스크 화면 (React, Create React App): `src/`
- NFC 리더기 프로그램 (Flask): `nfc_server.py`. 라즈베리파이에서 PN532 리더기로 태그를 읽습니다.
- 설치 스크립트: `deploy/`. 리더기 프로그램을 부팅 때 자동으로 띄우는 systemd 서비스와, 리더기를 zrok 터널로 내보내는 서비스를 등록합니다.

## 이 저장소에 없는 것 (팀원 담당)

- 백엔드 서버 (Django)
- AI 몽타주
- 모바일 앱

## 동작 흐름

1. GPS 키링(ESP32)이 자기 좌표를 백엔드로 보냅니다. 키링 쪽 코드는 이 저장소에 없습니다.
2. 키오스크에서 「키링 태그」를 누르고 키링을 NFC 리더기(PN532)에 댑니다.
3. 라즈베리파이의 `nfc_server.py`가 태그를 감지해 UID를 5초 동안 들고 있습니다.
4. 화면은 태그 대기 중 1초마다 리더기 프로그램의 `/check`에 물어 UID를 받습니다. 한 번 읽은 태그는 지워집니다.
5. 화면이 그 UID로 백엔드에서 키링의 최신 좌표를 받고, 측정한 지 5분이 안 된 실측값일 때만 「보호자에게 현재위치공유」 버튼을 켭니다.
6. 버튼을 누르면 그 좌표를 키오스크 ID와 함께 백엔드로 보냅니다.

## 화면 기능

- **시작 화면**: 단기 실종자와 장기 실종자를 10초마다 넘기는 슬라이드
- **실종자 정보**: 「찾는 중이에요」/「보호 중이에요」 탭, 분류(장애·치매·아동·기타) 필터, 17개 시·도 지역 필터. 경북/경상북도처럼 주소에 약칭과 정식 명칭이 섞여 들어오는 지역은 둘 다 조회해 합칩니다.
- **긴급 신고**: 키링 없이 누르면 키오스크 ID와 시각을 백엔드로 보냅니다.
- **키링 태그 후 위치 공유**: 위 동작 흐름대로 동작합니다. 좌표를 쓸 수 없으면 버튼을 회색으로 잠그고 이유를 함께 보여 주며, 등록되지 않은 카드를 대면 안내 문구를 띄웁니다.
- **안전 지도**: 카카오맵. 중부대학교 고양캠퍼스에서 시작하고 주변 위험시설(빨강)과 안전시설(파랑)을 표시합니다. 마커를 누르면 주소와 전화번호를 보여 주고, 「현재위치 재검색」을 누르면 지금 보이는 곳을 기준으로 다시 찾습니다.
- **자동 초기화**: 시작 화면이 아닌 곳에서 90초 동안 조작이 없으면 경고를 띄우고, 10초 뒤 처음 화면으로 돌아갑니다. 다음 사람이 앞사람의 태그 상태를 물려받지 않게 하기 위해서입니다.
- **오류 안내**: 실종자 목록을 불러오지 못하거나 리더기에 연결하지 못하면 이유를 화면에 띄웁니다.
- 화면 위쪽에는 웹캠 영상을 띄웁니다. 이 저장소의 코드는 영상을 화면에 보여 주기만 합니다.

## 실행 방법

### 화면

```bash
npm ci
npm start        # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (build/)
```

환경 변수는 `npm start`일 때 `.env.local` 등에서, 배포 빌드일 때 `.env.production`에서 읽습니다.

| 변수 | 내용 | 코드 기본값 |
|---|---|---|
| `REACT_APP_API_BASE` | 백엔드 주소. 끝에 `/`를 붙이지 않습니다. | 예시 주소 |
| `REACT_APP_NFC_URL` | 리더기 프로그램 주소 | `http://127.0.0.1:5000` |
| `REACT_APP_DEVICE_ID` | 이 키오스크의 ID. 긴급 신고와 위치 공유에 실어 보냅니다. | `KIOSK_001` |

안전 지도는 `public/index.html`에 있는 카카오맵 JavaScript 키를 씁니다. 이 키는 등록된 사이트에서만 동작하므로, 직접 띄워 보려면 본인 키로 바꿔야 합니다.

### 리더기 (라즈베리파이)

PN532를 SPI로 연결하고(CS 핀은 D5) `sudo raspi-config`에서 SPI를 켭니다.

```bash
python3 -m pip install adafruit-blinka adafruit-circuitpython-pn532 flask
python3 nfc_server.py                  # 5000번 포트에서 GET /check 에 응답
bash deploy/install-nfc-service.sh     # 부팅 때 자동으로 뜨도록 systemd 서비스 등록
```

라즈베리파이 OS Bookworm 이상에서 pip 설치가 `externally-managed-environment` 오류로 멈추면, 프로젝트 폴더에 가상환경(`.venv`)을 만들어 설치하거나 `--break-system-packages`를 붙입니다. 서비스 등록 스크립트는 프로젝트 안의 가상환경을 먼저 씁니다.

크롬 142부터는 https로 배포한 화면이 `http://127.0.0.1:5000`을 부르려면 키오스크 브라우저에서 「로컬 네트워크 액세스」 권한을 허용해야 합니다. 권한을 줄 수 없는 환경이면 `bash deploy/install-zrok-tunnel.sh <공유-이름>`으로 리더기를 zrok https 터널로 내보내고, 그 주소를 `REACT_APP_NFC_URL`에 넣습니다.

---

코드와 설정에 적힌 백엔드 주소와 배포 화면 주소(`dasibom-backend.example.com`, `dasibom-kiosk.example.com`)는 예시 값이고, zrok 터널 이름은 `<공유-이름>` 자리표시로 남겨 두었습니다. 테스트에 쓰인 사람 이름과 키링 번호도 지어낸 값입니다.
